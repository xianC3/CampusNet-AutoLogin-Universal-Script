校园网自动登录通用脚本（Windows）

一、安装

1. 运行构建生成的 CampusNetUniversal-Setup.exe。
2. 按向导完成安装；安装过程需要一次管理员授权。
3. 从开始菜单打开“校园网自动登录通用脚本”。

程序为自包含版本，不需要额外安装 .NET 运行时。

二、账号设置

1. 点击“账号设置”。
2. 账号栏只填写自己的学号或校园账号，不要手动添加 @ 后缀。
3. 选择接入运营商：
   校园网：不加后缀
   联通：@unicomyt
   移动：@cmccyt
   电信：@telecomyt
4. 填写密码并保存。

账号、密码或运营商选错时，校园门户会拒绝登录。重新打开“账号设置”修改即可，不需要重装。

三、连接接口设置

点击“连接设置”可以查看和修改：

1. 认证门户 URL。
2. Dr.COM 登录 API 端口。
3. 设备达到上限时是否允许自动注销旧会话。
4. 自助服务登录 URL。
5. 在线设备仪表盘 URL。

关闭自动注销后，设备达到上限时不会访问自助服务。开启后，程序会从
仪表盘 URL 自动派生在线列表和注销接口。

默认参数仅作为 Dr.COM 配置示例，不同学校或校区必须先修改并保存。

四、校园网名单

- “添加当前 Wi-Fi”将当前校园网络加入名单。
- “管理名单”可以查看和删除校园网名称。
- 家庭网络、手机热点及其他非名单 Wi-Fi 会直接跳过。

五、设备数达到上限

通用版不保存固定用户 MAC。仅在成功取得本机当前 MAC、识别验证码并读取在线会话列表后，才注销最旧的一条会话，尽量保留另一台设备在线。

无法取得本机 MAC、验证码不可靠、账号密码不正确或在线列表格式异常时，程序会停止注销，避免误删设备。

六、自动运行

- 勾选“登录 Windows 后自动在后台运行”。
- 程序使用当前用户计划任务，在登录后延迟约 5 秒启动。
- 网络变化和定时任务会重新检查。
- 关闭主窗口后程序留在系统托盘。

七、适用范围

默认参数仅作为 Dr.COM 配置示例。不同学校或校区必须在“连接设置”中
修改认证门户、登录 API 端口、自助服务登录及仪表盘 URL，并保存后再测试。

八、安全与日志

密码使用 Windows DPAPI 加密，只保存在当前 Windows 用户目录。程序不会把账号密码写进日志。卸载请使用开始菜单或 Windows“应用和功能”。
