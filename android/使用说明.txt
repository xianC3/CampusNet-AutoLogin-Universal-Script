校园网自动登录通用脚本（Android）

一、安装

1. 安装构建生成的 APK。
2. 打开应用，按系统提示允许定位、附近设备和通知权限。
3. 保持系统“定位”开关开启，否则部分 Android 手机不会返回 Wi-Fi 名称。

二、首次设置

1. 账号栏只填写自己的学号或校园账号，不要手动填写 @ 后缀。
2. 选择学校要求的接入方式：
   校园网：不加后缀
   联通：@unicomyt
   移动：@cmccyt
   电信：@telecomyt
3. 填写密码，点击“保存账号并登录”。
4. 连接校园 Wi-Fi，点击“添加当前 WI-FI 为校园网”。

三、连接接口设置

点击“连接接口设置”可以查看和修改：

1. 认证门户 URL。
2. Dr.COM 登录 API 端口。
3. 设备达到上限时是否自动注销旧会话。
4. 自助服务登录 URL。
5. 在线设备仪表盘 URL。

关闭自动注销后，设备达到上限时不会访问自助服务。开启后，应用会自动
使用仪表盘 URL 派生的在线列表和注销接口。

默认地址仅作为 Dr.COM 配置示例，不同学校或校区必须先修改并保存。

四、管理校园网名单

- 在校园不同位置遇到新的校园 Wi-Fi 时，连接后点击“添加当前 WI-FI 为校园网”。
- 点击“管理校园网名单（可删除）”，选择网络并确认即可删除。
- 只有名单中的 Wi-Fi 会触发校园门户登录；家庭网络、热点和其他 Wi-Fi 会跳过。

五、后台权限

小米 HyperOS：开启自启动，将省电策略设为“无限制”，允许后台活动。

荣耀 MagicOS：点击应用中的“打开自启动/权限设置”，在“应用启动管理”中关闭自动管理，允许自启动、关联启动和后台活动。

其他品牌：在应用信息或手机管家中允许自启动及后台运行。

六、适用范围

默认参数仅作为 Dr.COM 配置示例。不同学校或校区必须在“连接接口设置”
中修改认证门户、登录 API 端口、自助服务登录及仪表盘 URL，并保存后再测试。

七、安全

通用版不预置任何个人账号、密码、MAC 地址或个人校园 Wi-Fi 名称。遇到账号欠费、过期、停用或学校门户限制时，软件无法绕过，需要联系校园网管理部门。
